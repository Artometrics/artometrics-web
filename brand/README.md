# Artometrics brand assets

## SVG kit (`brand/svg/`)

Web copies are mirrored to `public/images/brand/svg/`.

| Asset | Use |
|-------|-----|
| `monogram-a-black.svg` | Light backgrounds |
| `monogram-a-white.svg` | Dark backgrounds |
| `monogram-a-red.svg` | Marketing / accent (`#C0392B`) |
| `monogram-a-currentColor.svg` | Inherit CSS `color` |
| `wordmark-*.svg` | Wordmark alone (Chomsky via `/fonts/Chomsky.otf`) |
| `lockup-horizontal-*.svg` | A + Artometrics in a row |
| `lockup-stacked-*.svg` | A above wordmark |
| `favicon.svg` / `app-icon-*.svg` / `og-mark.svg` | Icons & social |

PNG raster marks remain in `public/images/brand/` for native Expo. Prefer SVG on web.
