# TikTok / Shorts script — Trophic memory (deer antlers)

**Length target:** 55–75 seconds  
**On-screen title:** How damage sticks to deer antlers year after year  
**Credit:** Michael Levin on trophic memory (Bubenik antler archive)  
**Hashtags:** #deer #science #hunting #Artometrics #ScienceDesk

## Hook (0–3s)
“Cut one spot on a deer antler. It heals. Then the whole rack falls off.”

## Beat 1 — The return (3–20s)
“Next year, a new rack grows — with an extra branch at the exact place you damaged.”
“That’s trophic memory. The scar is gone. The address is not.”

## Beat 2 — Where can it live? (20–40s)
“It can’t store the map in the bone that left.”
“So the body has to remember where in the branch structure the injury was — likely in the growth zone on the scalp — then imprint that turn onto next year’s bone cells: two centimeters forward, take a right.”

## Beat 3 — The archive (40–60s)
“Anthony and George Bubenik tracked this for decades.”
“Levin got a letter: thirty-five years of labeled antlers in a garage. Thirteen boxes. Every rack named. CT-scanned at the vet school.”
“One experiment is ten-plus years. You’re not getting a grant for that now.”

## Close (60–75s)
“Standard morphogenesis tools — local gradients, gene networks — are not built for a memory that survives the structure it describes.”
“Full sources and next steps: Artometrics science desk — trophic memory.”
