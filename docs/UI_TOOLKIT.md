# UI toolkit references (vibe-coder set)

Pattern sources for motion and polish on Artometrics **tools** surfaces. Magazine chrome stays on Artometrics tokens (`constants/Colors.ts`, Chomsky, accent red). Do not wholesale install shadcn stacks into the Expo RN tree.

| Site | URL | How we use it |
|------|-----|----------------|
| KokonutUI | https://kokonutui.com | Subtle glass/blur cues on web only |
| React Bits | https://reactbits.dev | Shader/gradient inspiration for `.web.tsx` accents |
| Bklit | (chart/video kits) | Inspiration; keep Plotly for article charts |
| Limora | https://limora.ai | On-brand image direction; generate via Higgsfield → `public/images/tools/` |
| Anime.js | https://animejs.com | Web SVG / scroll micro-motions |
| Motion | https://motion.dev | Web motion; shared UI prefers `react-native-reanimated` |
| Rive | https://rive.app | Optional later |
| Magic UI | https://magicui.design | Beam / globe patterns — reimplemented lightly (see `ToolsAccent.web.tsx`) |

Shipped motion: tools hub enter fade, Twilda cover press opacity, Aftercare tarot reveal, ToolsAccent beam on web.
