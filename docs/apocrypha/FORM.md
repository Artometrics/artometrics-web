# Apocrypha — form guide

Each story is a **complete exposé**, not a traditional short-story arc with scenes and dialogue as the primary engine. Dialogue can appear as quoted testimony, leaked chat logs, or hearing transcripts — always framed as evidence.

## Reader contract

Open every piece with a clear fiction marker, then commit to the report voice as if the marker weren’t there.

Recommended opening device (pick one per story; stay consistent inside a piece):

1. **Editor’s note (prefatory):** *This report is fiction. Names, institutions, and datasets are invented.*
2. **Desk slug:** `APOCRYPHA · FICTION` in the eyebrow / TOC header
3. **Seal at the end only:** if you withhold the marker until the close, the final note must be unmistakable — never leave a reader thinking Artometrics published a real investigation

Default for the book manuscript: **prefatory note** (honest up front) + full immersion after.

## Structural skeleton (steal from Content OS, then twist)

Mirror the Artometrics report shape so the costume fits:

1. **Dek / lead** — 2–4 paragraphs. Lead with the finding, not the setup.
2. **Research question** — one sharp question the “investigation” answers
3. **Fast facts** — 3–6 invented-but-internally-consistent numbers or labels
4. **Body sections** — mechanism → timeline → power map → human cost → institutional denial
5. **Limitations** — what the “data” cannot prove (use this to plant dread or irony)
6. **Editor’s note / method** — sourcing theater: FOIA-ish requests, leaked CSVs, anonymous operators, archival footage
7. **Optional download rail parody** — “Dataset (CSV)” / “Hearing transcript” as literary props, not live links

You do **not** need Plotly charts. If a visual helps, describe it in prose (*Figure 2 plots…*) or use a simple ASCII/table block. Print packs can invent figure plates later.

## Voice

Same as Artometrics nonfiction:

- Professional, objective, insightful, **no fluff**
- Named and dated “facts” only — even when invented
- One calm expert voice — not thriller prose, not pulp
- Mechanism over mood; let dread emerge from the ledger

Allowed texture borrowed from Wired / long-form investigation:

- Scene-setting ledes that still land a claim in the first screen
- Named sources with job titles (composites)
- Document dumps summarized, not pasted in full
- A mid-piece turn where the investigation reframes what the opening claimed

Forbidden texture:

- “Little did they know” omniscient novelist voice
- Multi-POV chapter hopping inside one story
- Explaining the metaphor to the reader
- Real living private individuals as thinly veiled villains

## Consistency rules for invented facts

Inside one story:

- Numbers must not contradict each other
- Dates must form a readable timeline
- Institutions need one primary name and at most one alias
- If you invent a statute, acronym, or metric, define it once, then reuse it cold

Across the book:

- Shared universe optional, not required
- Recurring desk, paper, or “Apocrypha Archive” frame is allowed if it helps the collection feel like one object
- Do not force crossover for its own sake

## Length targets

| Tier | Words | Use when |
|------|-------|----------|
| Dispatch | 1,200–2,000 | Single mechanism, one twist |
| Cover story | 2,500–4,500 | Full Wired-length investigation |
| Special report | 5,000–8,000 | Rare; only if the archive/timeline needs the room |

Default collection mix: mostly cover stories, a few dispatches as palate cleansers.

## Ending modes

Pick deliberately; don’t default to twist-for-twist’s-sake:

1. **The ledger closes** — the finding holds; the cost is clear
2. **The limitation is the horror** — what can’t be measured is the point
3. **Institutional shrug** — everyone knows; nobody can act
4. **Broken seal** — the fiction marker lands as thematic payload (use sparingly)
5. **Open FOIA** — the story ends on a pending request / unfinished dataset

## Checklist before a story is “done”

- [ ] Fiction marker present
- [ ] Opening finding could pass as a real magazine dek
- [ ] Fast facts exist and don’t contradict the body
- [ ] At least one document / dataset / hearing prop
- [ ] Limitations section does real work (not boilerplate)
- [ ] No real private person is identifiable as a target
- [ ] Title could sit on a Wired or Artometrics cover without looking like genre fiction
