05 — Do / Don't
Do
Full-bleed hero on promo surfaces
Brand as hero-level signal
Hard 2px rules between sections
One claim per chart, source line always visible
Flush-left type, sparse red
Don't
Purple gradients or cream/terracotta
Hero badges, chips, floating stickers
Cards as decoration (no real interaction)
Soft multi-layer shadows or glow
Generic Inter/SaaS dashboard first-viewport
